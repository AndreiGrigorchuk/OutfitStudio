# Outfit Studio

**A minimalist iOS application for creating, styling, and organizing fashion collages.**

Outfit Studio is an independent iOS fashion application built with Swift and SwiftUI. It combines a refined, editorial-inspired interface with an interactive workspace for creating personalized outfit compositions.

The application is designed around simplicity, creative freedom, and a monochromatic visual identity inspired by luxury fashion aesthetics.

## Features

### Collage Editor

- Import clothing and accessory photos from the iPhone photo library.
- Freely arrange images on an interactive canvas.
- Move, resize, and organize fashion items.
- Customize collage backgrounds and frames.
- Create personalized outfit compositions.

### My Collages

- Browse outfit collages in a vertically scrollable gallery.
- Add personal notes and descriptions to outfits.
- Edit and manage existing collages.
- Save and delete outfit compositions.

## Tech Stack

- **Language:** Swift

- **Development Environment:** Xcode
- **Version Control:** Git & GitHub

## Architecture and Development

Outfit Studio is being developed as a native iOS application, focusing on declarative UI development, interactive gestures, state management, and a clean, maintainable codebase.

## Getting Started

1. Clone the repository:

   `git clone https://github.com/AndreiGrigorchuk/OutfitStudio.git`

2. Open `OutfitStudio.xcodeproj` in Xcode.

3. Select an available iPhone Simulator.

4. Build and run the application.
